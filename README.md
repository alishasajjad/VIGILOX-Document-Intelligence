# VIGILOX Document Intelligence

An AI-powered document intelligence system designed to automate the extraction, validation, and review of structured information from security guard licenses, identification documents, and SIA badges using OCR and LLM-based document processing.

The project focuses on building a reliable, production-oriented pipeline with schema validation, field-level confidence scoring, expiry and anomaly detection, human-in-the-loop review, and comprehensive audit logging.

> **Note:** This project is currently under active development. The architecture, features, and implementation will evolve throughout the development and evaluation phases.
